# Kasus

Anda ditugaskan oleh suatu perusahaan roti untuk membuat aplikasi mobile untuk penjualan roti secara online. Aplikasi tersebut dapat menampilkan roti-roti baru yang dijual oleh perusahaan tersebut. Di dalam aplikasi tersebut terdapat informasi kue yang dijual beserta harganya dan orang lain dapat membelinya secara langsung. Transaksi pembelian roti atau kue tersebut hanya meminta data dari pelanggan beserta point koordinat rumah yang memanfaatkan GPS di smartphone pelanggan. Data tersebut disimpan dalam server dan admin dari perusahaan tersebut bisa melihat data pelanggan yang memesan roti atau kue tersebut. Maka buatlah aplikasi sederhana untuk menyelesaikan tugas diatas!
